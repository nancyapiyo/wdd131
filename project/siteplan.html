1. Site Name

Gulu Vulnerable Children Volunteer Hub. Supporting vulnerable children in Gulu is a meaningful local need, and building a dynamic web directory makes it easier for community members to find trusted ways to volunteer and stay informed.

Optional domain: guluvcvhub.org

2. Site Purpose

The purpose of the Gulu Vulnerable Children Volunteer Hub is to provide a centralized platform for volunteers and community members to connect with opportunities to support vulnerable children in the Gulu region.

3. Scenarios

  • It will feature program directories (such as tutoring, mentorship, and community drives), volunteer roles and schedules,basic guidelines for working with children, and local contact details.

4. Color Schema

This document uses the exact palette planned for the live site:

Deep Leaf Green (#1E4D3B)

Used for primary headings, navigation bar accents, and key section borders.

Warm Terracotta (#B85D3B)

Used for secondary highlights, callout badges, and link hover states.

Soft Sand (#FAF7F2) & Charcoal (#1F2421)

Soft Sand sets the page background; Charcoal keeps body text crisp and readable.

5. Typography

Two web fonts from Google Fonts balance editorial warmth with clean readability:

  • Fraunces — Used for h1 and h2 headings to give titles a welcoming, distinct character.
  • Plus Jakarta Sans — Used for body paragraphs, lists, navigation items, and UI labels.
